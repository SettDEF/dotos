# dotos

Tasks: a CLI (`dotos`), a Quickshell window and a terminal view, sharing one store.

- `dotos/`: the app (the `dotosd` CLI and daemon, the window in QML, docs)
- `dotos-tui/`: the terminal view
- `icalcore/`: the calendar core it reads and writes

Install: `cd dotos && ./install.sh` (needs cargo; quickshell for the window).
